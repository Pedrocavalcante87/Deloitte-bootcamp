# Dia 00 — Case 01: Git, Padrão de Commits e Organização do Repositório

Este dia consolida o **padrão do bootcamp** para trabalhar com um repositório único no GitHub, mantendo tudo organizado por pastas de dias e com desenvolvimento feito na branch `develop`.

---

## ✅ Objetivos do Dia 00

- Entender o fluxo básico de Git usado no bootcamp
- Padronizar commits (mensagens e consistência)
- Aprender comandos de navegação no terminal (PowerShell)
- Garantir que o desenvolvimento acontece na branch `develop`

---

## 🌿 Estrutura de Branches (padrão do bootcamp)

- `main`: branch estável (evitar commits diretos)
- `develop`: branch de desenvolvimento (onde fazemos os commits do dia a dia)

### Checar branch atual

```bash
git branch
git status
```
