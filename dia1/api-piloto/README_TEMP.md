# Dia 01 — API Piloto (.NET)

## Sobre a atividade

Esta atividade tem como objetivo **criar uma API base em .NET**, apenas para entender como funciona a estrutura de uma API e como realizar consultas pelo Swagger.

Não existe regra de negócio definida, banco de dados ou camadas extras. A ideia é somente iniciar uma API, rodar o projeto e acessar os endpoints via Swagger.

Essa API foi criada como um **projeto piloto**, conforme orientação do auxiliar.

---

## O que foi feito

- Criação de um projeto Web API em .NET
- Execução da aplicação localmente
- Acesso e uso do Swagger
- Teste de endpoint simples para validação

---

## Como executar o projeto

No terminal, a partir da raiz do repositório, execute:

```bash
cd dia1/api-piloto
dotnet run
```
