# Dia 02 — Case 2.1: Sistema de Check-in (Console)

## Sobre a atividade

Neste case a proposta foi criar um sistema simples de check-in de visitantes no console, com um menu para cadastrar, listar, buscar e registrar saída.

O exercício também pede o uso de `ArrayList` (requisito) e `List<T>` como apoio para trabalhar de forma mais organizada.

## O que foi pedido

- Menu em loop (console)
- Cadastrar visitante
- Listar visitantes
- Buscar visitante pelo nome
- Registrar saída
- Usar `ArrayList` como parte do exercício
- Usar `List<T>` para apoiar o controle de dados (quando necessário)

## Como executar

```bash
cd dia2/case-02-1-checkin
dotnet run
```
